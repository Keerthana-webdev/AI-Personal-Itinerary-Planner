## AI Personal Itinerary Planner
A simple web application that helps users plan their trips quickly.

--- 

### Features
- Enter destination, number of days, and budget
- Generates a day-wise travel itinerary
- Shows estimated trip cost
- Provides a packing list
- Displays the destination map

--- 

### Technologies Used
- HTML
- CSS
- JavaScript

--- 

### How to Run
1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in a browser or run using Live Server

--- 

### Purpose
This project was created as part of a Web Sprint activity to demonstrate how AI-inspired tools can help users generate quick travel plans.
